# Задача 1. Локальная передача версий мира

Цель: после закрытия мира или остановки сервера передать его на другой компьютер,
а после следующей сессии отправить только недостающие данные. Получатель должен
получить точное сохранение, включая удаления, без потери предыдущей рабочей версии.

Большая задача разделена на семь частей. Общая дорожная карта и правила отметки
прогресса — в [README задач](README.md); идеи проекта — в [концепции](concept.md).

## Зависимости

```text
1.1 → 1.2
1.3 → 1.4
1.1 + 1.4 → 1.5
1.2 + 1.4 + 1.5 → 1.6 → 1.7
```

Обработка ошибок и сохранность данных обязательны с первых частей; 1.6 — общий
аудит отказов, а не разрешение отложить защиту данных до конца.

## Границы этапа

- Мир закрыт и неизменен на время публикации. Снимки работающего мира в этап не входят.
- Обмен идёт поверх общего `Connection`; TCP используется в доверенной сети.
- Одна выбранная ветка продолжения игры; при конфликте сохраняются обе.
- Автоматическое объединение миров не требуется.
- Код не должен зависеть от знания формата `.mca`; оптимизации по игровым чанкам
  или rsync рассматриваются отдельно после измерений.
- Клиентский интерфейс показывает прогресс и ошибки; перенос прикладной координации
  в `agent` относится к следующим этапам и не отменяет уже готовый движок в `core`.

Сервер обнаружения, интернет-подключение, постоянный агент, переработка CLI и
передача роли хоста вынесены в [общую дорожную карту](README.md#дорожная-карта).

## Условие закрытия

Все семь подзадач отмечены, воспроизводимый сценарий «игра → закрытие → передача →
игра на другом ПК → повторное обновление» пройден. Есть результаты приёмки,
замеры и список ограничений. Наличие кода или синтетического теста само по себе
не подтверждает открытие настоящего мира в Minecraft.

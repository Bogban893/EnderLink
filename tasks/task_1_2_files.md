# 1.2. Файлы, каталоги и докачка

[Этап 1](task_1.md) · Зависит от [1.1](task_1_1_tcp.md), от её ручной LAN-приёмки не зависит.

## Результат

Отдельный файл или дерево каталогов передаётся потоково с проверкой целостности,
прогрессом и продолжением после обрыва. Это общий файловый протокол, не история миров.

## Прогресс реализации

- [x] Передаются файлы, вложенные и пустые каталоги; весь файл не загружается в память.
- [x] Проверяются размеры и SHA-256; отправитель ждёт итогового подтверждения.
- [x] Проверенные блоки сохраняются для продолжения, повреждённые запрашиваются заново.
- [x] Для файлов и каталогов CLI поддерживает ограниченные повторы подключения и понятное завершение после их исчерпания.
- [x] Существующий чужой результат не перезаписывается; потеря подтверждения не создаёт вторую копию.
- [x] Написаны тесты обрывов, пустых данных, смены содержимого, небезопасных путей и ссылок.

## Где смотреть и проверять

- `core/src/main/kotlin/org/enderlink/transfer`, включая `protocol` и `resume`.
- `cli/src/main/kotlin/org/enderlink/cli/command/TransferRetry.kt`.
- [Команды файловой передачи](../cli/README.md).

```bash
./gradlew :core:test --tests 'org.enderlink.transfer.*'
./gradlew :cli:test --tests '*TransferRetryTest'
```

Реализация и локальные тесты есть. Передача на физических компьютерах и обрыв
реальной сети проверяются в [1.7](task_1_7_acceptance.md).

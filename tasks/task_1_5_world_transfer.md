# 1.5. Передача версии и только недостающих блоков

[Этап 1](task_1.md) · Зависит от [1.1](task_1_1_tcp.md) и [1.4](task_1_4_repository.md).

## Результат

Два хранилища обмениваются версией поверх общего `Connection`. Полный манифест
задаёт точное дерево, а получатель запрашивает только отсутствующие объекты.

## Прогресс реализации

- [x] Есть отдельный протокол мира `ELW4`, работающий через TCP и iroh.
- [x] Первая передача, обновление, удаления и пустые каталоги обрабатываются по полному манифесту.
- [x] При отсутствии изменений не пересылаются полезные данные; изменение одного блока не требует отправки всего файла.
- [x] Запросы объектов объединяются в группы; получатель проверяет объекты и подтверждает версию после активации.
- [x] После обрыва повторная операция использует сохранённые проверенные объекты; неполная версия не активируется.
- [x] Конфликт сохраняет входящую ветку и прежнюю рабочую копию.
- [x] Есть команды публикации, статуса, checkout, отправки и приёма; написаны локальные тесты TCP и iroh.

## Где смотреть и проверять

- `core/src/main/kotlin/org/enderlink/worldtransfer`.
- `cli/src/main/kotlin/org/enderlink/cli/command/WorldCommand.kt`.
- [Протокол и замеры на синтетических данных](../docs/world-versions.md).

```bash
./gradlew :core:test --tests '*WorldTransferTest' --tests '*WorldIrohTransferTest'
```

Реализация и локальные интеграционные тесты есть. Возобновление версии мира сейчас
требует повторного запуска операции; автоматические повторы файлового CLI не следует
считать автоматическим восстановлением всех операций мира.

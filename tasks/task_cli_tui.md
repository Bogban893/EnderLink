# CLI: единый терминальный интерфейс

Связанные задачи: B08 (CLI), B02 (общий агент), B07 (библиотека миров).

## Выбранный UX

Панели сверху показывают миры, друзей и операции. Снизу постоянно доступна
командная строка EnderLink с историей и подсказками. Кнопки и ввод команд
обращаются к одному обработчику и обновляют одно состояние. Это один интерфейс,
а не отдельные приложения CLI и TUI. Нижняя строка не выполняет команды ОС.

```text
EnderLink                       Мир | Друзья | Помощь
---------------------------------------------------
Хранилище: ...                  Друзья:
Версия: ...                     alex — статус неизвестен
[Выбрать] [Обновить]             [Обновить]
---------------------------------------------------
Результаты действий и прогресс
> repository "путь к хранилищу"
Подсказка аргумента / варианты дополнения
```

Первоначальный запуск — явная команда `cli tui`. Обычный запуск без аргументов
и существующие одноразовые команды сохраняют поведение. Полноэкранный режим
требует терминала; перенаправленный ввод/вывод не должен получать управляющие коды.

## Первый этап

- [x] Полноэкранное окно с панелями и строкой команд.
- [x] Общий обработчик для кнопок и команд; работа с диском вне потока интерфейса.
- [x] Просмотр существующего репозитория и локального профиля друзей.
- [x] Дополнение команд по Tab, подсказки аргументов и история текущего сеанса.
- [x] Пути с пробелами, кириллицей и разделителями Windows.
- [x] Восстановление терминала при выходе и ошибке, проверка виртуальным терминалом.
- [x] Темы mono, Ender / Void и btop: переключение кнопкой или командой, сохранение выбора.
- [x] Мышь для кнопок и фокуса, подсветка наведения; выход по F10/Ctrl+Q, удаление слова по Ctrl+W.
- [x] Рамки и размеры панелей при изменении терминала; компактные кнопки слева в два ряда.
- [x] Статус выполнения под блоком «Команда EnderLink», подробности ошибок в «Результате».
- [x] Минимум 80×24: сообщение при недостатке места, блокировка скрытых элементов, восстановление данных, ввода и фокуса после увеличения.

## Операции миров и профиля

- [x] Выбор существующего или нового каталога хранилища без создания при выборе.
- [x] Публикация закрытого мира с явным `--closed`, список известных версий и checkout.
- [x] Импорт владельца старого мира по явному UUID через общий обработчик CLI.
- [x] Отправка и приём миров по TCP/iroh через обработчики обычного CLI и протокол `core`.
- [x] Фазы и прогресс во время операции, отмена сетевого ожидания/передачи с сохранением докачки.
- [x] Защита публикации и активации от принудительного прерывания; выход дожидается записи.
- [x] Явное создание профиля, добавление/удаление друзей и обновление панелей.
- [x] Дополнение путей каталогов, параметров, загруженных имён друзей и ID версий вне потока интерфейса.
- [x] Проверка аргументов общим парсером CLI; неполный ввод остаётся в строке.
- [x] Меню действий «Мир», «Передача», «Друзья» и «Профиль».

Полноценная библиотека нескольких миров остаётся отдельной задачей B07.
Чтение профиля сохраняет его блокировку; занятый профиль даёт понятную ошибку.
Наличие друга в списке не подтверждает online или готовность принимать мир.

## Далее

Дополнение имён миров после B07 и подсветка ввода развивают эффект «мини-LSP».
Дополнение путей/друзей/версий и диагностика неполных аргументов уже реализованы;
отдельный LSP-сервер не используется. Описание команд общее для исполнения,
справки и подсказок.

Передача и отмена используют общие обработчики CLI и транспорт `core`. После B02
подключить TUI к локальному API агента, получать снимок и события. До этого
не обещать продолжение операции после закрытия интерфейса или параллельную
работу CLI/GUI с одним профилем. Блокировку профиля не снимать.

Историю команд пока хранить только в памяти. Не писать в неё секреты.
Локализация интерфейса остаётся отдельным улучшением.

Реализация первого этапа: `cli/tui` (`TuiSession`, `TuiWindow`, `CommandInput`).
Основание: `TuiSessionTest`, `CommandInputTest`, `TuiApplicationTest`,
`TuiWindowTest`, `TuiThemeSettingsTest`, `TuiOperationsTest`, `TuiCompletionsTest`,
тесты `WorldRepository` и сборка CLI. Локальный TCP проверяет отмену ожидания,
повторный запуск и успешную передачу. Файловые тесты проверяют публикацию,
версии, отказ checkout при неопубликованных изменениях и пересечение каталогов.
Локальный iroh-узел без публичных сервисов проверяет прерывание ожидания подключения.
Виртуальный терминал проверяет
темы, границы панелей, запуск и выход при малом размере, восстановление после увеличения.
Нативная консоль Windows пока не подключена; первая цель запуска — Linux/WSL.
Ручная проверка реальных терминалов, Minecraft и интернет-iroh остаётся открытой.

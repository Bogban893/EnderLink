# 1.4. Хранилище, активация и конфликты

[Этап 1](task_1.md) · Зависит от [1.3](task_1_3_manifest.md).

## Результат

Опубликованные объекты и история хранятся отдельно от рабочей копии. Новая
проверенная версия активируется безопасно, с возможностью восстановления и checkout.

## Прогресс реализации

- [x] Есть публикация закрытого мира, хранение манифестов и объектов по хешу.
- [x] Одинаковые объекты переиспользуются; публикация неизменного дерева не создаёт лишнюю версию.
- [x] Новая копия собирается в staging и проверяется до активации, включая удаления.
- [x] Сохраняются предыдущая копия и маркер незавершённого переключения; есть восстановление после перезапуска.
- [x] Независимые ветки сохраняются обе; неопубликованные локальные изменения блокируют замену.
- [x] Есть явный checkout, чтение старого формата и локальные тесты конфликтов, повреждений и прерывания активации.

## Где смотреть и проверять

- `core/src/main/kotlin/org/enderlink/world/WorldRepository.kt`.
- [Устройство хранилища](../docs/world-versions.md).

```bash
./gradlew :core:test --tests '*WorldRepositoryTest'
```

Реализация и локальные тесты есть. Рабочая копия и staging должны позволять
атомарное переименование на одном томе. Пиковое место на диске проверяется в 1.7;
защита от нехватки места дополнительно рассматривается в 1.6.

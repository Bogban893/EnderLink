# 1.3. Манифест закрытого мира и файловые блоки

[Этап 1](task_1.md) · Зависимостей нет.

## Результат

Версия однозначно описывает всё дерево закрытого мира, его историю и порядок
блоков. Движок работает с локальными каталогами без зависимости от сети и CLI.

## Прогресс реализации

- [x] Есть постоянный `worldId`, `versionId`, `parentVersionId` и отдельный `treeHash`.
- [x] Манифест содержит полный состав дерева, включая пустые каталоги; отсутствие пути означает удаление.
- [x] Файлы читаются потоково и разбиваются на фиксированные блоки по 256 КиБ с SHA-256.
- [x] Хеш дерева не зависит от порядка обхода; идентификатор версии учитывает историю и схему блоков.
- [x] Проверяются относительные пути, ссылки и корректность манифеста; формат документирован.
- [x] Написаны тесты изменений, удалений, большого файла, идентификаторов и опасных путей.

## Где смотреть и проверять

- `core/src/main/kotlin/org/enderlink/world/WorldManifest.kt` и `WorldManifestIO.kt`.
- [Формат манифеста](../docs/world-versions.md).

```bash
./gradlew :core:test --tests '*WorldManifestTest' --tests '*WorldTransferProtocolTest'
```

Реализация и локальные тесты есть. Согласованность источника обеспечивается
закрытием игры или остановкой сервера; проверка размера файла не заменяет снимок.

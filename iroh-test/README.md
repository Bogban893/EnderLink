# Минимальный iroh-чат

Отдельный Kotlin/JVM-модуль на `computer.iroh:iroh:1.2.0`.
Постоянный ID, сохранённые друзья, чат и проверка бинарных данных.
Повторно пересылать временные коды приглашения и ответа не требуется.

Используется стандартный preset `N0`: публичный поиск адресов и relay iroh.
Вы сами не запускаете сервер. Приложение ищет друга по его публичному ключу,
пробует прямое соединение и может передавать данные через relay. Соединение
шифруется; входящие подключения разрешены только добавленным друзьям.

## Сборка

Нужна Java 21:

```bash
./gradlew :iroh-test:installDist
```

Скрипт запуска: `./iroh-test/build/install/iroh-test/bin/iroh-test`.
В Windows: `gradlew.bat` и `iroh-test\build\install\iroh-test\bin\iroh-test.bat`.
Артефакт iroh 1.2.0 содержит готовые нативные библиотеки для Linux x64/arm64,
Windows x64 и macOS arm64. Другие платформы этим модулем не проверялись.

## Первый запуск: один раз обменяться ID

На **каждом** компьютере:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test id
```

Скопируйте значение после `Ваш ID:` и отправьте другу. Это постоянный публичный
ID, а не временный код подключения.

На первом компьютере добавьте ID второго:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test add друг <ID-второго>
```

На втором аналогично добавьте ID первого:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test add друг <ID-первого>
```

Вместо `<ID-второго>` / `<ID-первого>` вставляется полученная строка без угловых
скобок. Имена локальные: каждый выбирает своё имя для друга.
Допускаются буквы, цифры, `_` и `-`, до 40 символов.

## Чат

Первый компьютер:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test listen
```

Дождитесь `Ожидание сохранённого друга…`.
Второй компьютер:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test connect друг
```

После `Чат открыт` вводите сообщения. Команды:

- `/probe` — отправить 32 КиБ случайных данных и проверить подтверждение SHA-256.
- `/status` — показать текущий выбранный путь: напрямую или через relay.
- `/quit` или конец ввода — закрыть соединение и завершить процесс.

Изменения выбранного пути выводятся автоматически. Первоначальный relay может
позже смениться прямым соединением. Успешный чат сам по себе не доказывает,
что маршрут прямой: смотрите `/status`.

Каждый процесс обслуживает одну сессию. Для следующего разговора повторите
`listen` и `connect друг`. **Добавлять друга снова не нужно**, даже после
перезапуска или смены сети. Входящему соединению от неизвестного ID будет
отказано, после чего `listen` продолжит ждать.

## Профиль и друзья

По умолчанию профиль находится в `~/.enderlink/iroh-test` (домашняя папка
пользователя Java). Внутри:

- `secret.key` — секретный ключ, от которого зависит постоянный ID;
- `friends.properties` — локальные имена и публичные ID друзей;
- `profile.lock` — блокировка одновременного запуска двух процессов с одним профилем.

Ключ создаётся один раз; повреждённый ключ не заменяется автоматически.
Для резервной копии сохраните профиль, когда утилита остановлена. Другу
передаётся только публичный ID, а не `secret.key`. На Linux/macOS создаваемые
файлы ключа и друзей доступны только владельцу (`600`).

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test friends
./iroh-test/build/install/iroh-test/bin/iroh-test remove друг
```

Замена ID под существующим именем требует сначала удалить старую запись.
Чтобы создать второй независимый профиль на том же компьютере, добавляйте
`--profile <каталог>` к **каждой** команде:

```bash
./iroh-test/build/install/iroh-test/bin/iroh-test id --profile ./profile-a
./iroh-test/build/install/iroh-test/bin/iroh-test id --profile ./profile-b
```

Относительные пути считаются от рабочей папки терминала.

## Сеть и ограничения

Сеть должна позволять доступ к публичным сервисам поиска и relay iroh.
Ожидание выхода узла онлайн и поиска друга ограничено 60 секундами на каждый этап.
Оба участника должны быть онлайн и добавить друг друга. После сбоя попробуйте
заново запустить `listen` / `connect` с теми же профилями; новые ID не нужны.

VPN и смена сети могут изменить маршрут или оборвать сессию. Автоматическое
восстановление после полного разрыва пока не реализовано. Для проверки связи
без VPN держите его выключенным на всём протяжении опыта; альтернативно
исключите Java из туннеля в настройках VPN.

Публичные relay предоставляются сторонним проектом и имеют ограничения скорости
и доступности. Это экспериментальная версия; группы, передача пользовательских
файлов, интеграция с `core`/`cli`, пароли профиля и Minecraft-туннель пока не добавлены.

## Проверки

```bash
./gradlew :iroh-test:test
```

Автотесты не требуют публичных relay: проверяют сохранение ID и друзей,
повреждённый ключ, блокировку профиля, отказ неизвестному участнику и надёжный
обмен текстовыми и бинарными сообщениями между двумя локальными узлами.

# EnderLink coordinator

Небольшой сервис обнаружения для передачи миров через iroh. Он хранит только ID,
адреса соединения, список ID друзей с правом поиска, признак готовности и время
последнего обновления. Миры, ключи профиля и сообщения чата через него не проходят.

```bash
./gradlew :coordinator:installDist
ENDERLINK_COORDINATOR_PORT=28770 ./coordinator/build/install/coordinator/bin/coordinator
```

Сервис слушает только `127.0.0.1`. На машине с публичным IP разместите перед ним
HTTPS reverse proxy с действующим сертификатом и передайте адрес вида
`https://example.org/` пользователям Desktop. Порт процесса не открывайте в
интернет напрямую. Настройте перезапуск процесса и ограничение запросов на proxy.
Публикация на реальном сервере и проверка разных сетей пока не выполнены.

Desktop на вкладке **Друзья** сохраняет адрес координатора. Пустое поле оставляет
обычный поиск iroh. При недоступности сервиса Desktop сообщает об этом и пробует
обычное соединение iroh. Relay iroh остаётся запасным маршрутом; свой relay пока
не реализован. Координатор не создаёт виртуальную сеть и не заменяет проверку ID
друга при защищённом соединении iroh.

## Доступ и состояние

Перед регистрацией и поиском клиент получает одноразовый challenge (30 секунд).
Запрос формата `ELD1` подписывается постоянным ключом профиля; сервис проверяет
подпись по указанному ID. Запись содержит только разрешённые ID из списка друзей
владельца. Поиск выдаёт адреса и готовность только указанному в этой записи другу,
который сам зарегистрирован. Отказ доступа выглядит как неизвестное состояние и не
выдаёт существование записи. Отдельные аккаунты и приглашения сейчас не нужны:
обмен ID и добавление в друзья уже являются явным действием пользователей.

Desktop обновляет регистрацию примерно каждые 20 секунд во время операции.
Запись считается актуальной 60 секунд после последнего обновления. `offline`
означает только устаревшую запись с момента запуска сервиса; отсутствие записи
или запрет доступа означает `unknown`. `ready` означает, что Desktop сейчас ждёт
входящее соединение для мира. Проверку фактической готовности завершает `READY`
протокола передачи после подтверждения получателя. Время последнего обновления —
часы сервера. Записи старше суток удаляются при следующей регистрации; после
перезапуска сервиса каталог пуст и состояние неизвестно до новой регистрации.

Локальные тесты `:coordinator:test` проверяют подпись, повтор запроса, права
доступа, свежую и устаревшую запись. HTTPS proxy, NAT и сохранность соединения
между настоящими компьютерами требуют отдельной ручной приёмки.

# EnderLink

Приложение для передачи миров Minecraft Java между компьютерами и запуска
локального Vanilla-сервера. Через графический интерфейс можно добавлять друзей,
передавать миры через интернет или локальную сеть и продолжать игру с полученной копии.
При повторной передаче отправляются только недостающие данные.

## Требования

- JDK 21 для сборки и Java 21 для запуска готового дистрибутива.
- Графическая сессия для настольного приложения.
- Интернет при первой сборке для загрузки Gradle и зависимостей.
- Совместимые версии Minecraft на компьютерах участников.

Gradle устанавливать отдельно не нужно: в проекте есть Gradle Wrapper.

## Запуск

Из корня проекта на Linux/macOS:

```bash
./gradlew :desktop:run
```

В Windows:

```powershell
.\gradlew.bat :desktop:run
```

Для запуска без Gradle соберите дистрибутив:

```bash
./gradlew :desktop:installDist
./desktop/build/install/desktop/bin/desktop
```

В Windows используйте `gradlew.bat :desktop:installDist`, затем
`desktop\build\install\desktop\bin\desktop.bat`.
Для переноса на другой компьютер копируйте всю папку `desktop/build/install/desktop/`;
на компьютере получателя нужна Java 21. Доступность нативных библиотек зависит
от ОС и архитектуры; собирайте и проверяйте дистрибутив под платформу получателя.

## Передача мира

1. Закройте мир в Minecraft или остановите сервер. Не меняйте файлы во время передачи.
2. На каждом компьютере выберите вверху окна отдельную папку **хранилища мира**.
   В ней EnderLink хранит версии и рабочую копию; она должна быть отдельно от
   исходного сохранения, папки Minecraft `saves` и каталога сервера.
3. Для передачи через интернет откройте **Друзья**, обменяйтесь ID и добавьте
   друг друга. Собственный сервер связи поднимать не требуется.
4. Получатель открывает **Принять мир**, выбирает друга, папку `saves` своей
   установки Minecraft и имя папки мира, затем нажимает **Ждать мир**.
5. Отправитель открывает **Отправить мир**, указывает папку закрытого мира,
   выбирает друга и нажимает **Отправить мир**. Если нужная версия уже находится
   в хранилище EnderLink, поле источника можно оставить пустым.
6. После успешного приёма мир появляется в списке одиночной игры Minecraft.

Для локальной сети вместо друга выберите TCP: отправитель указывает IP получателя,
обе стороны — одинаковый порт. TCP используйте только в доверенной сети:
этот режим не шифрует соединение и не проверяет участников.

При следующем обмене используйте те же хранилища и имя папки мира. Открытый в игре
или изменённый локально мир не заменяется. После закрытия игры при необходимости
нажмите **Обновить Minecraft**. Если версии разошлись, EnderLink сохраняет обе ветки
и предлагает явно выбрать входящую. Ожидание и передачу можно отменить; при повторе
уже полученные проверенные данные используются снова.

Если лаунчер использует собственный каталог игры, выберите его папку `saves` вручную.
Подробности, включая перенос инвентаря владельца старого мира, — в
[руководстве Desktop](desktop/README.md).

## Запуск Minecraft-сервера

1. Выберите хранилище с опубликованной или полученной версией мира.
   Её состояние отображается на вкладке **Обзор**.
2. Подготовьте совместимый `server.jar` и отдельную папку с `eula.txt`.
   После ознакомления с EULA и её принятия укажите в этом файле `eula=true`.
   В `server.properties`, если он используется, задайте `online-mode=true`
   и `level-name=world`.
3. На вкладке **Сервер** выберите подготовленную папку и `server.jar`, затем
   нажмите **Запустить сервер**.
4. Для завершения используйте **Сохранить и остановить**: изменения мира
   сохранятся новой версией в хранилище.

Каждый запуск создаёт отдельную папку в `enderlink-sessions` с копией мира
и журналом. При закрытии окна с работающим сервером приложение предлагает
сохранить мир и остановить сервер. Автоматической передачи роли хоста пока нет:
после остановки передайте новую версию другу, чтобы он запустил её у себя.

Работа без GUI и подключение к серверу через игровой туннель описаны в
[руководстве агента](agent/README.md).

## CLI

Соберите CLI и запустите терминальный интерфейс с панелями и строкой команд:

```bash
./gradlew :cli:installDist
./cli/build/install/cli/bin/cli tui
```

TUI поддерживает публикацию закрытого мира, просмотр версий, отправку и приём
по TCP/iroh, управление друзьями, прогресс и отмену. Запуск — в Linux, macOS или
WSL, терминал UTF-8 от 80×24 символов. Нативная консоль Windows пока не подключена.

Обычные команды работают без TUI: `cli --help`. Сценарии передачи, настройка
профиля, команды TUI и ограничения описаны в [руководстве CLI](cli/README.md).

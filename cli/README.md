# Локальный чат и передача файлов и каталогов

Собрать утилиту:

```bash
./gradlew :cli:installDist
```

В первом терминале запустить ожидание одного подключения:

```bash
./cli/build/install/cli/bin/cli listen --port 25570
```

Во втором терминале подключиться:

```bash
./cli/build/install/cli/bin/cli connect --host 127.0.0.1 --port 25570
```

Для проверки на двух компьютерах установить утилиту на обоих и заменить
`127.0.0.1` локальным IP принимающего компьютера. Принимающая сторона по
умолчанию слушает все сетевые интерфейсы; для проверки только на своём
компьютере можно указать `listen --host 127.0.0.1`.

## Передача одного файла

Режим выбирается при запуске. Для чата используются `listen`/`connect`, для
файла — `receive`/`send`. Обе стороны должны выбрать соответствующий режим.
Команды ниже выполняются после сборки `:cli:installDist`.

На получателе:

```bash
./cli/build/install/cli/bin/cli receive --output ./received --port 25570
```

На отправителе:

```bash
./cli/build/install/cli/bin/cli send --host 127.0.0.1 --port 25570 --file "./my world.zip"
```

Для другого компьютера заменить `127.0.0.1` его локальным IP. Каталог
получения создаётся автоматически. Файл получает исходное имя; существующий
файл с таким именем не перезаписывается. Каждая команда обслуживает один файл
и завершается. Чат и передачу можно запускать одновременно на разных портах.

Файл передаётся блоками по 256 КиБ без загрузки целиком в память. Обе стороны
показывают прогресс. Получатель пишет во временный `.part`, проверяет размер
и SHA-256, затем публикует файл и отправляет подтверждение. 100% прогресса
означает передачу байтов; успех отправитель сообщает после подтверждения.

При ошибке или обрыве временный файл удаляется, докачка пока не реализована.
При аварийном завершении процесса `.part` может остаться. После публикации
файл остаётся у получателя, даже если подтверждение не дошло до отправителя.
Таймаут ожидания входящих данных или ответа — 30 секунд; это не ограничение
общего времени передачи. Исходный файл нельзя изменять во время отправки.
Синхронизация изменений пока не поддерживается.

## Передача каталога

На получателе используется та же команда `receive`: она автоматически
определяет, отправлен файл или каталог. На отправителе выбрать `--directory`
вместо `--file`:

```bash
./cli/build/install/cli/bin/cli receive --output ./received
./cli/build/install/cli/bin/cli send --host 127.0.0.1 --directory "./Мой мир"
```

Команды выполняются в разных терминалах или на разных компьютерах. На
получателе появится `received/Мой мир` со всеми файлами, подпапками и пустыми
каталогами. Показывается общий прогресс по сумме размеров файлов. Каждый файл
проверяется по SHA-256. Передача завершается подтверждением всего дерева.
Нужна обновлённая сборка CLI на обоих компьютерах.

Данные сначала собираются в отдельном временном каталоге `.enderlink-*` и
публикуются под исходным именем после полной проверки. Существующий файл или
каталог с таким именем не перезаписывается. При обрабатываемой ошибке временное
дерево удаляется; при аварийном завершении процесса оно может остаться.

Передаётся всё содержимое, включая скрытые и пустые файлы. Символические
ссылки и специальные файлы отклоняются. Права доступа, владельцы и времена
файлов не сохраняются. Пока нет докачки, объединения с существующим каталогом
и отправки только изменений.

Исходное дерево должно оставаться неизменным от начала сканирования до
окончания передачи. Для Minecraft нужно выйти из мира или остановить сервер:
обычное копирование файлов работающего мира не гарантирует согласованность.

## Работа чата

Вводимые строки отправляются собеседнику в UTF-8. `/quit` или конец
стандартного ввода закрывают соединение и завершают сессию. После отключения
собеседника процесс также завершается. Повторное подключение требует нового
запуска команды. Предел одного сообщения — 1 МиБ в UTF-8.

Можно запускать через Gradle в двух терминалах:

```bash
./gradlew --console=plain :cli:run --args="listen --port 25570"
./gradlew --console=plain :cli:run --args="connect --host 127.0.0.1 --port 25570"
```

Готовый скрипт из `installDist` удобнее для интерактивного ввода. В Windows
используются `gradlew.bat` и `cli.bat` из соответствующих каталогов. Нужна Java 21.

## Автодополнение в Bash

Из корня проекта подключить скрипт для текущего терминала:

```bash
source ./cli/completion/cli.bash
```

После этого Tab дополняет команды и подходящие им флаги, после `--file` —
пути к файлам и каталогам, после `--output` и `--directory` — только каталоги. Уже указанные
флаги повторно не предлагаются. Адрес и порт вводятся вручную.

Работает для `cli` из PATH, путей `./cli/build/install/cli/bin/cli` и
`cli/build/install/cli/bin/cli` от корня проекта, а также абсолютного пути
к собранному скрипту. Для другого пути или псевдонима нужно зарегистрировать
его явно, например `complete -F _enderlink_cli_complete my-cli`.
Внутри `gradlew --args="..."` дополнение не применяется.

Для постоянного подключения добавить в `~/.bashrc` строку с абсолютным путём
к скрипту (заменить путь своим):

```bash
source "/путь/к/EnderLink/cli/completion/cli.bash"
```

Примеры: `cli con` + Tab дополняется до `cli connect`,
`cli send --f` + Tab — до `cli send --file`. Если вариантов несколько,
двойное нажатие Tab показывает их список при стандартных настройках Bash.

Справка: `cli --help`. Код завершения: `0` — обычный выход, `1` — ошибка
ввода-вывода, `2` — неверные аргументы.

Это прототип для доверенной локальной сети: шифрование и аутентификация пока
не реализованы. Если второй компьютер не подключается, проверить IP,
доступность порта в межсетевом экране и изоляцию клиентов Wi-Fi.
